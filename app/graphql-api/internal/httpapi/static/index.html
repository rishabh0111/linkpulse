LinkPulse

A URL shortener with click analytics. Shorten a link, open it, and watch its clicks arrive. The app is kept small on purpose: it is the workload for the deployment, monitoring and chaos platform around it.

No API behind this page. It was opened as a file, so there is no service to call. Start the stack with mise run dev and open linkpulse.localtest.me:8088.

  1. Shorten a long URL below.
  2. Open the short link. Each visit counts as a click.
  3. Watch the clicks arrive, refreshed every 3 seconds.

http and https only; other schemes are refused.

Analytics

The feed polls recentClicks; there is no subscription, by design.
